# Просмотр экспорта Claude

Один HTML-файл — `claude-export-viewer.html` — для чтения архива, который присылает claude.ai по кнопке **Настройки → Конфиденциальность → Экспортировать данные**.

## Как пользоваться

1. Скачайте `claude-export-viewer.html` и откройте его двойным щелчком в браузере (Chrome, Edge, Firefox, Safari последних версий).
2. Перетащите в окно JSON-файл из письма. Появится список архивов экспорта с кнопками «Скачать» и сроком действия ссылок (24 часа).
3. Скачайте нужные архивы и добавьте их туда же кнопкой «Добавить скачанные архивы…» или перетаскиванием. Можно выбрать сразу несколько ZIP: распаковывать их не нужно, всё откроется как один экспорт.

Также можно открыть сразу один или несколько ZIP-архивов или отдельные JSON-файлы из них.

Интернет не нужен: всё работает локально, файлы никуда не отправляются.

## Что умеет

- **Скачать архивы**: таблица из JSON-файла письма с кликабельными ссылками, статусом каждого архива («открыт здесь» / «ссылка открывалась») и временем до истечения ссылок.
- **Чаты**: список с поиском по названию или по всему тексту, сортировка, читаемый вид сообщений (форматирование, код, таблицы, размышления, вызовы инструментов, вложения).
- **Скачивание**: любой чат в Markdown, JSON или HTML; несколько выбранных чатов (или все сразу) одним ZIP с артефактами и текстом вложений.
- **Артефакты**: собираются из чатов с учётом всех правок, есть предпросмотр HTML/SVG/Markdown, выбор версии, скачивание по одному или все в ZIP.
- **Проекты**: описание, инструкции, документы проекта и его чаты; скачивание проекта в ZIP.
- **Файлы**: всё содержимое архива с просмотром и скачиванием отдельных файлов.
- **Сведения**: статистика, данные аккаунта, память Claude.
- **Оформление**: светлая, тёмная и бирюзовая темы; ширину левой панели можно менять, потянув за границу (двойной щелчок возвращает исходную).
- **Сохранённые архивы**: открытые архивы можно запоминать в браузере, чтобы потом открывать их без повторного выбора файла (отключается галочкой на стартовом экране).

Сами загруженные в чаты картинки и PDF claude.ai в экспорт не кладёт: просмотрщик показывает только их названия и извлечённый текст, если он есть.

## Установка как приложение (Edge, Chrome)

Установить страницу как приложение браузер разрешает только по адресу https, поэтому она публикуется через GitHub Pages:

1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите *Source: Deploy from a branch*, ветку с этим файлом и папку `/ (root)`, нажмите **Save**.
3. Через минуту-две откройте https://dyslexia2813.github.io/Claude-Arch-Viewer/ в Edge и нажмите «Установить приложение» вверху страницы (или значок установки в адресной строке).

Установленное приложение открывается отдельным окном, работает без интернета и умеет открывать ZIP/JSON двойным щелчком («Открыть с помощью»).

Файлы для приложения: `manifest.webmanifest`, `sw.js` (офлайн-кэш), `icons/`, `index.html` (перенаправляет на просмотрщик). Сам `claude-export-viewer.html` по-прежнему работает и как отдельный файл с диска.
