# Просмотр экспорта Claude

Один HTML-файл — `claude-export-viewer.html` — для чтения архива, который присылает claude.ai по кнопке **Настройки → Конфиденциальность → Экспортировать данные**.

## Как пользоваться

1. Скачайте `claude-export-viewer.html` и откройте его двойным щелчком в браузере (Chrome, Edge, Firefox, Safari последних версий).
2. Перетащите в окно ZIP-архив из письма целиком (распаковывать не нужно) или отдельные JSON-файлы из него.

Интернет не нужен: всё работает локально, файлы никуда не отправляются.

## Что умеет

- **Чаты**: список с поиском по названию или по всему тексту, сортировка, читаемый вид сообщений (форматирование, код, таблицы, размышления, вызовы инструментов, вложения).
- **Скачивание**: любой чат в Markdown, JSON или HTML; несколько выбранных чатов (или все сразу) одним ZIP с артефактами и текстом вложений.
- **Артефакты**: собираются из чатов с учётом всех правок, есть предпросмотр HTML/SVG/Markdown, выбор версии, скачивание по одному или все в ZIP.
- **Проекты**: описание, инструкции, документы проекта и его чаты; скачивание проекта в ZIP.
- **Файлы**: всё содержимое архива с просмотром и скачиванием отдельных файлов.
- **Сведения**: статистика, данные аккаунта, память Claude.
- **Сохранённые архивы**: открытые архивы можно запоминать в браузере, чтобы потом открывать их без повторного выбора файла (отключается галочкой на стартовом экране).

Сами загруженные в чаты картинки и PDF claude.ai в экспорт не кладёт: просмотрщик показывает только их названия и извлечённый текст, если он есть.
